# Figures

Submission-ready EDA and evaluation diagrams generated from versioned metrics/data.

Minimum set:

- Data-cleaning funnel.
- Rating and label distributions.
- Aspect co-occurrence heatmap.
- Model comparison.
- Per-label F1 and support.
- Precision-recall curves.
- Confusion matrices.
- Reliability diagram.
- Geographic coverage map.
- Evidence correctness and ranking evaluation.

Every figure should have a companion source-data file or generating notebook/script reference.
