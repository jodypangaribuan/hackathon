# Raw Data

Immutable organizer-provided input snapshots.

Do not edit or normalize files in this directory. Prefer a symlink, Drive mount, or configured path to the workspace `Datasets/` directory. Record for every source:

- Original filename and source.
- Access/snapshot date.
- SHA-256 hash.
- Encoding and delimiter.
- License/usage terms.

Raw data is intentionally excluded from Git.
