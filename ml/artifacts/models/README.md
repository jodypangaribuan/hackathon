# Model Artifacts

Versioned keyword, TF-IDF, IndoBERT, tokenizer, threshold, and calibration artifacts. Model weights are not committed to Git.

Recommended naming:

```text
keyword-v1/
tfidf-aspect-v1/
indobert-aspect-v1/
indobert-polarity-v1/
indobert-severity-v1/
```

Each directory needs a manifest with model ID/license, config hash, data hash, annotation/split version, metrics reference, and created timestamp.
