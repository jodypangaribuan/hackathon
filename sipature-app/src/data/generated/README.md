# Generated A9 Application Data

These files are generated by `npm run data:a9` from the hash-locked A9 r5
restricted export and metadata-only enrichment.

The generator enforces:

1. Exact export hash and model/schema versions.
2. Canonical identity, taxonomy, coordinate, count, and priority gates.
3. Missing severity semantics and unresolved-destination exclusion.
4. Removal of evidence text and review-level identifiers.
5. Expected 388 destinations, 322 mappable destinations, 103 actionable
   destinations, and 210 candidate interventions.

Evidence text is intentionally absent pending privacy review. Do not replace
these files with the restricted `app-export.json` directly.
